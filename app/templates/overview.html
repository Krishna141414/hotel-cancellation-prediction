The problem

Binary classification

Predict is_canceled for a booking at the moment it is made. About {{ "%.1f"|format(dataset.train_cancel_rate * 100) }}% of bookings are canceled. If a hotel knew which ones, it could overbook just enough to keep rooms full without having to relocate guests.

  • Missed cancellation (false negative): the room stays empty and revenue is lost.
  • False alarm (false positive): the room is overbooked and a guest may need relocating.
  • Because of the imbalance, accuracy alone would mislead: always guessing "not canceled" is already {{ "%.1f"|format((1 - dataset.test_cancel_rate) * 100) }}% accurate. Models are ranked on PR-AUC, with recall, precision, F1 and ROC-AUC alongside.

Validation setup

  • Hold-out test set (20%, stratified, seed {{ setup.random_state }}), used once after the model was frozen.
  • Stratified {{ setup.cv_folds }}-fold CV on the training set for every comparison, tuning and selection decision.
  • No leakage: scaling, log transforms and one-hot categories are fitted inside each CV fold.
  • Temporal check: trained on earlier arrivals and tested on the latest period to measure drift.
  • Threshold picked from out-of-fold predictions ({{ final.threshold }}), not from the test set.
