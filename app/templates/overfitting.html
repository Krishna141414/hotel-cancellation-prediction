How to read it

  • assigned_room_type is set at check-in, which canceled bookings never reach, so it quietly encodes the answer.
  • booking_changes is a count taken at the outcome date: bookings canceled early had less time to change.
  • Both lift the score, which is exactly the warning sign. They're excluded so the model works at booking time.
  • days_in_waiting_list is known when the booking is confirmed, so it stays (and barely matters).
  • country / is_domestic lift the score a lot too, but nationality may only be recorded at check-in. As the safer option they're dropped; the with-vs-without numbers are on the Model comparison page.
